## 它能解决什么问题

在 AutoCAD / SouthMap 的**布局（图纸空间）**里出图时，经常遇到这种情况：

- 视口边框是**倾斜**的（比如沿河道、道路走向布置的长条视口）
- 视口里的图形也跟着**歪了**，横不平竖不直
- 手动用 `UCS → Z → PLAN` 转正时，SouthMap（中望内核）报 **`变量设置被拒绝：CVPORT`**，或者干脆转了没反应

TiltViewport 就是为这个场景写的：

1. **不碰 `CVPORT`、不激活视口**——直接设置视口对象的 `TwistAngle`（视图扭转角）属性，绕开中望内核的安全拦截
2. **只转视图、不动图形**——图形的真实坐标一个字节都不改，转歪了随时重来
3. **回读校验**——转正后打印视口实际生效的角度，确认真的设置进去了

## 功能一览

| 命令 | 作用 | 适用场景 |
|---|---|---|
| **`TVR`** | **转正现有视口里的倾斜图形**（核心命令） | 视口已存在，里面的图形是歪的 |
| `TVP` | 把图纸空间里画好的闭合矩形转成视口 | 已画好倾斜矩形，只是转不成视口 |
| `TVQ` | 两角点 + 旋转角，一键生成倾斜视口 | 从零开始做倾斜视口 |
| `TVU` | 解锁当前布局所有视口 | 返工重调时 |

> 所有命令行提示均为**纯英文 ASCII**，彻底避免中文编码在 CAD 控制台里显示成问号/方块乱码。

## 安装与加载

1. 下载本仓库的 `TiltViewport.lsp`（约 12 KB，纯文本）。
2. 在 CAD 命令行输入 `APPLOAD` 回车，打开「加载/卸载应用程序」对话框。
3. 浏览选中 `TiltViewport.lsp`，点「加载」。
4. 命令行出现下面这行即成功：

```
===== TiltViewport v2.2 loaded (angle fix). Commands: TVR / TVP / TVQ / TVU =====
```

> **一劳永逸**：在 APPLOAD 对话框里把该文件加入「启动组」，以后每次开 CAD 自动加载。

> **换版本务必重新加载**：如果命令行显示的还是 `v2.0` 或 `v2.1`，说明加载的是旧文件——先用新文件覆盖旧文件，再重启 CAD 或重新 `APPLOAD`。旧版本有角度换算 bug（见[常见问题](#常见问题排查)）。

> **关于乱码**：插件提示全是英文，不会出现问号乱码。若 `命令:` 等 CAD 自带中文提示仍是乱码，那是 CAD 界面字体问题，与本插件无关。

## 核心用法：TVR 转正现有视口

适合：**视口已经画好了，但里面的图形是歪的，想把它转正。**

### 操作步骤

1. 点底部「**布局1**」标签，进入**图纸空间**（看得见虚线页面边框的状态）。
2. 命令行输入 `TVR` 回车。
3. `Select the VIEWPORT to straighten (click its border):`
   → **点一下要处理的视口边框**（锁定的视口也能选，插件会自动临时解锁）。
4. `Pick a reference LINE to make horizontal, or press Enter to type angle:`
   → 这里二选一：
   - **直接回车（推荐、最稳）** → 进入手动输角度模式，见下节符号判断；
   - **选参考线**：先双击进入视口，选一条「本该水平」的线（带状图边线、道路中心线、房屋轴线等），插件自动算出应转的角度。
5. `Twist angle in deg (0=reset, +/- flips direction) <0>:`
   → 输入角度（详见下节），如 `-36`；输 `0` 恢复原方向。
6. 成功时命令行显示：

```
  Applied twist = -36.00 deg
  Verified twist = -36.00 deg
[DONE] View straightened. If direction is wrong, run TVR again with opposite sign.
```

### 角度该输多少？符号判断（重点）

这是最容易搞混的地方。记住一句口诀：

> **视图要往图形倾斜的「相反方向」扭回来。图形逆时针歪，就输负数；图形顺时针歪，就输正数。**

判断方法（用 CAD 的「测量角度」或看 UCS 图标）：

| 图形/UCS 的 X 轴指向 | 倾斜方向 | TVR 应输入 |
|---|---|---|
| 指向**右上**（如你测出的 36°） | 逆时针 | **`-36`** |
| 指向**右下** | 顺时针 | **`36`** |

**你那张截图的实例**：X 轴箭头指向右上、测量角 36°，属于逆时针倾斜 → **输入 `-36`**。

**不确定怎么办**：两次必有一次对。先输 `-36`，看屏幕效果；在图变得更歪就再跑一次输 `36`。反正 `TVR` 只改视图不改图形，随便试，没有破坏性。

**验证技巧**：看 `Verified twist =` 这一行的回读值。它等于你输入的角度，就说明属性真的写进去了；若视图没变化但回读正常，检查是不是选错了视口。

### 为什么要转正

倾斜视口里，图形沿视口长边方向显示本身没错，但如果你需要：

- 读出水平的坐标/方向
- 让图例、注记水平
- 和正置的别的视口统一方向

就需要把视图转正。转正后记得在视口里补一个**指北针**——因为视图转了以后，真北不再朝上。

## 其他命令

### TVQ — 一键建倾斜视口

1. 切到图纸空间，`TVQ` 回车。
2. 点矩形第一角点 → 点对角点（在图纸空间画矩形）。
3. 输入旋转角度（如 `25` 顺时针为负 `-25`）。
4. 输入比例分母（`1000` = 1:1000）。
5. 自动完成：画倾斜矩形 → 转视口 → 设比例 → 锁定。

### TVP — 用你画好的倾斜矩形

1. 切到图纸空间（⚠️ 必须在图纸空间，矩形画在视口里是不行的）。
2. 若矩形画在了模型空间，删掉，用 `REC` 在图纸空间重画 + `RO` 旋转。
3. `TVP` 回车 → 选那个闭合矩形。
4. View twist angle 一般直接回车（默认 0）。
5. 输入比例分母 → 完成。

### TVU — 解锁全部视口

想返工重调时，`TVU` 回车解锁当前布局所有视口。

## 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| **命令行全是 `???` 乱码** | 旧版 LSP 中文提示在编码转换中损坏 | 用 v2.2，提示全英文 |
| **`变量设置被拒绝：CVPORT`** | SouthMap / 中望内核拦截 LISP 改 `CVPORT` | v2.2 完全不碰 CVPORT，改用 TwistAngle |
| **输入角度后视图没反应，显示 `11511906.57 deg` 这种天文数字** | v2.1 角度换算 bug：把「度→弧度」写成了 `度×π×180`（应为 `÷180`），36° 变成 20357.5 弧度 = **3240 整圈**，转回原位 | 升级 v2.2（已修复，并有回读校验） |
| **转正后方向反了（更歪）** | 角度符号输反 | 再跑一次 `TVR` 输相反数 |
| **`[ERROR] This CAD does not expose TwistAngle`** | 该 CAD 版本视口对象没有 TwistAngle 属性 | 手动双击进视口，用 `DVIEW → TW` 命令转正 |
| **视口转出来显示不全** | 视图被转到图形范围外 | `TVU` 解锁 → 双击进视口 `Z` → `E`（满屏）→ 重设比例 |
| **`[ERROR] Please select a VIEWPORT border`** | 选中的不是视口边框 | 点视口的**边框线**，不要点里面的图形 |

## 工作原理

核心是设置图纸空间 **VIEWPORT 对象的 `TwistAngle` 属性**（单位：弧度），它对应 DXF 中视图的扭转角：

```lisp
(vla-put-TwistAngle viewportObject angleInRadians)
```

为什么不用别的办法：

- **`setvar CVPORT` 激活视口** → 被 SouthMap / 中望内核安全策略拦截（报错）。
- **`entmod` 改 DXF 组码 50/51** → 实测被 CAD 拒绝（`MOD_FAIL`），视图属性受保护。
- **`vla-put-TwistAngle`** → 唯一在图纸空间直接可用、无需激活视口的可靠 API。

角度换算统一走两个 helper，杜绝 v2.1 那种写反除法的事故：

```lisp
(defun _tv:d2r (d) (* d (/ pi 180.0)))   ; 度 → 弧度
(defun _tv:r2d (r) (* r (/ 180.0 pi)))   ; 弧度 → 度
```

## 版本历史

- **v2.2** — 修复角度单位换算 bug（v2.1 把 36° 转成 3240 整圈导致「没反应」）；新增 `Verified twist` 回读校验；修正 `TVP`/`TVQ` 中同类换算。
- **v2.1** — 改用 `TwistAngle` 属性，绕开 SouthMap 对 `CVPORT` 的拦截；提示全英文。
- **v2.0** — 新增 `TVR` 转正命令；全部提示改 ASCII。
- **v1.x** — 初版：`TVP` / `TVQ` 建倾斜视口。
