# 倾斜视口助手 v2.2 · 使用说明

AutoCAD / 南方 SouthMap 通用的 AutoLISP 小插件。**核心功能：现有视口里把倾斜图形转正（`TVR`），全部提示为纯英文（无乱码）。**

> **v2.2 重要修复（角度单位 bug）**：v2.1 里度数转弧度写反了（`度×π×180` 而非 `度×π÷180`），导致输入 36° 实际转了 3240 整圈（回到原位，看起来"没反应"），并显示 `Applied twist = 11511906.57 deg` 这种离谱数字。v2.2 已修正全部换算，并显示 `Verified twist` 回读值确认真实生效角度。

## 一、加载插件（每次开 CAD 做一次）

1. 命令行输入 `APPLOAD` 回车
2. 找到 `TiltViewport.lsp`（或 `倾斜视口助手.lsp`，内容相同），点「加载」
3. 命令行出现 `===== TiltViewport v2.2 loaded (angle fix). Commands: TVR / TVP / TVQ / TVU =====` 即成功（**请确认是 v2.2**，旧版本务必用新文件覆盖后再加载）

> 想一劳永逸：在 APPLOAD 对话框里把它加入「启动组」，以后开 CAD 自动加载。

> **关于乱码**：v2.0 的提示全部是英文（如 `[DONE] View straightened`），不会再出现问号/方块乱码。命令行里 AutoCAD 自身的中文提示（如「命令:」）若仍是乱码，那是 AutoCAD 界面字体问题，与插件无关。

## 二、★ 核心用法：TVR —— 现有视口里把倾斜图形转正

适合「视口已经在了，但里面的图形是歪的，想把它转正」。

> **v2.1 修复**：SouthMap（中望内核）会拦截 `setvar CVPORT`，导致旧版报「变量设置被拒绝：CVPORT 3」。新版**完全不碰 CVPORT、不激活视口**，改为直接设置视口的 `TwistAngle`（视图扭转角）属性——在图纸空间点选视口即可完成。

1. 点底部「布局1」进入**图纸空间**
2. 命令行输入 `TVR` 回车
3. `Select the VIEWPORT to straighten` → **点一下要处理的视口边框**（锁定的视口也能选，插件会自动临时解锁）
4. `Pick a reference LINE...` → 二选一：
   - **直接回车（推荐、最稳）** → `Twist angle in deg` 输入角度，如 `25` 或 `-25`；输 `0` 恢复原方向。转正过头就输相反数再跑一次
   - **选参考线**：双击进入视口后，选一条「本该水平」的线（带状图边线、道路中心线等），插件自动算扭转角
5. 命令行显示 `Applied twist = 36.00 deg` 和 `Verified twist = 36.00 deg`（回读值应与输入一致），再显示 `[DONE] View straightened.` 即完成

**原理**：直接设置视口的 `TwistAngle`（DXF 里视图的扭转角），**只旋转视图显示方向，不改动任何图形的真实坐标**，可放心用。方向反了就再运行一次 `TVR` 输入相反数。

> **验证要点**：v2.2 会回读实际生效角度。`Verified twist` 若与你输入的角度一致（如输入 36、显示 36.00），说明设置成功；若视图看起来没变，检查该视口是否是你要处理的那个。

## 三、创建倾斜视口（如果还没有视口）

### TVQ —— 一键全自动（推荐新手）

适合「从零开始做一个倾斜视口」。

1. 点底部「布局1」进入**图纸空间**
2. 输入 `TVQ` 回车
3. 按提示：点矩形第一角点 → 点另一角点 → 输入旋转角度（如 `25`，顺时针为负 `-25`）
4. 输入比例分母（如 `1000` 表示 1:1000）
5. 完成：倾斜矩形 → 视口 → 设比例 → 自动锁定，一步到位

### TVP —— 用你画好的倾斜矩形

适合「我已经画好了倾斜矩形，只是转不成视口」。

1. 点底部「布局1」进入**图纸空间**（⚠️ 必须在图纸空间，不能是模型空间）
2. 如果之前矩形画在了视口里面（模型空间），先删掉，在图纸空间重新用 `REC` 画矩形 + `RO` 旋转出角度
3. 输入 `TVP` 回车 → 选择那个倾斜矩形
4. 「View twist angle」一般**直接回车**（默认 0，图形顺着视口边框）
5. 输入比例分母（如 `1000`）→ 完成

## 四、辅助命令

- `TVU` —— 解锁当前布局所有视口（想返工重调时用）

## 五、命令与提示速查

| 命令 / 提示 | 含义 |
|---|---|
| `TVR` | 现有视口内把倾斜图形转正（选参考线 或 输入角度 / W） |
| `TVQ` | 两角点 + 旋转角一键建倾斜视口 |
| `TVP` | 把图纸空间已有闭合矩形转成视口 |
| `TVU` | 解锁全部视口 |
| `Reference line angle` | 你选的参考线当前的倾斜角 |
| `Tilt angle in deg` | 手动输入倾斜角；`0` = 世界坐标朝上，`W` = 世界视图 |
| `Scale denominator <1000>` | 1:N 里的 N，带状图常用 1000 / 2000 |

## 六、注意

- 视口转出来后若显示不全：解锁视口（`TVU`）→ 双击进去 `Z` → `E`（满屏）→ 再重设比例
- 倾斜视口里要标**指北针**：视口转了角度后，真北不再朝上
- `TVR` 只改视图方向不改图形坐标；若转正后想恢复原样，再运行 `TVR` 输入 `W` 即可
